### Sobre el uso del automata
Los automatas estan programados para leer las **primeras** cadenas escritas en **cada linea.**
- El Automata Finito **Determinista** lee: _AFDcadenas.txt_
- El Automata Finito **No Determinista** lee: _AFNDcadenas.txt_

## Caso 1: Cajero automatico
Para la primera aplicación, en este caso de un AFD, nos situaremos en la necesidad de utilizar un cajero automático, el cual nos pedirá nuestra clave o PIN del cual solo tendremos tres intentos para acceder, de lo contrario se bloqueara. Luego aceptar la clave, nos permitirá retirar dinero o ver nuestro saldo, mostrándonos el monto de la cuenta y nos entrega la tarjeta. Además, antes y después de colocar el PIN podremos cancelar la operación y el cajero nos devolverá la tarjeta.
Para esta aplicación se restringe o se considerara estos parámetros para realizar la explicación, puesto que si consideramos todas las variables que se usan en la realidad el modelo se extiende demasiado o incluso seria necesario utilizar otros modelos.
